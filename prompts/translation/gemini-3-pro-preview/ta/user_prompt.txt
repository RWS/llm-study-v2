இந்தப் பத்தியை மொழிபெயர்க்கவும்:

<உள்ளீட்டு_பத்தி>
{input_paragraph}
</உள்ளீட்டு_பத்தி>

அசல் பத்தியையும் அதன் மொழிபெயர்ப்பையும் கீழே கொடுக்கப்பட்டுள்ள JSON கட்டமைப்பில் வழங்க நினைவில் கொள்ளவும். இதை ஒரு சாதாரண உரை வாக்கியமாக வழங்காமல், முழுமையாகப் பயன்படுத்தக்கூடிய ஒரு JSON ஆப்ஜெக்ட்டாக வழங்கவும். "```json" போன்ற வ்ராப்பர்களைப் பயன்படுத்தக்கூடாது; அதற்குப் பதிலாக, ஒரு கட்டமைக்கப்பட்ட பதில் வடிவத்தை உருவாக்கவும் (ஆங்கிலத்தில்: structured output).
